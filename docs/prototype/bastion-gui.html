bastion
Standalone SSH client — native on every platform, sync without an account.
Prototype The terminal is simulated — a web page cannot open real SSH connections. The commands answer with the same data the panels show. Try help.

Native per platform

SwiftUI on iOS/macOS, Kotlin on Android, WinUI 3 on Windows, GTK4 on Linux. No shared UI layer — just a common sync protocol.

Sync without sign-in

The host database is merged deterministically (last-write-wins + tombstones) through a file in a folder you already sync. The payload is AES-256-GCM encrypted on the device.

Open source

Apache-2.0 license, no container, no account. Keys never leave the device unencrypted.
