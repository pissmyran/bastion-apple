# Architecture

Bastion for Apple is a shared core with three apps on top.

```text
              +--------------------+
              |      SSHCore       |
              |  SwiftNIO SSH, NIO |
              +---------+----------+
                        |
       +----------------+-----------------+
       |                |                 |
  bastion-cli      iOS and macOS        tvOS
     Swift         App/ (SwiftUI)     App/TVApp/
```

## SSHCore

`Sources/SSHCore/` holds everything that is not user interface: SSH sessions, host key verification, SFTP, port and SOCKS forwarding, the host list, the sync engine and the encryption of the sync file. The core is built and tested with Swift Package Manager, without Xcode.

## The apps

- **iOS, iPadOS and macOS** share the code in `App/`. The terminal is built on SwiftTerm.
- **tvOS** lives in `App/TVApp/` and must not get SwiftTerm or APIs that tvOS lacks. Cloud sign-in uses the device flow.
- **The Xcode project** is generated by XcodeGen from `App/project.yml`. `App/Package.swift` is the dependency manifest that Renovate reads; it must never end up among the app's source files.

## Dependency boundaries

| Manifest | Owns |
| --- | --- |
| `Package.swift` | SSHCore and bastion-cli |
| `App/Package.swift` | The apps' Swift packages, for example SwiftTerm |
| `App/Gemfile` | fastlane |

Update a dependency in the manifest that actually owns it.

## Security boundary

SSHCore owns host key verification and authentication. The user interface must never build shortcuts around the core's checks. Keys and passwords are stored in the keychain, never in files in the repo or in test data.
